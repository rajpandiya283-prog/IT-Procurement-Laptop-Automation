# Phase 6 – Project Testing

## Testing Process

The Standard Laptop procurement automation was tested in ServiceNow.

### Test Steps

1. Open the Service Catalog.
2. Select Standard Laptop.
3. Place the laptop order.
4. Open the Request record.
5. Verify the approval status.
6. Open the Requested Item.
7. Open the Catalog Tasks section.
8. Verify that the Catalog Task was created.
9. Verify the Short Description.
10. Verify the Assignment Group.

## Expected Result

The Catalog Task should be created automatically after the required approval and should contain:

- Short Description: Laptop need to Configured
- Assignment Group: Hardware
- Approval: Approved

## Test Result

The Catalog Task was successfully created and the required task details were displayed.
