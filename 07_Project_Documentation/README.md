# Phase 7 – Project Documentation

## Project Overview

This project automates the Standard Laptop procurement process using ServiceNow Flow Designer.

## Milestone 1 – Flow

A Flow named Standard laptop task was created using Flow Designer. The flow uses a Service Catalog trigger and a Create Catalog Task action.

## Milestone 2 – Flow Assignment

The Standard laptop task flow was assigned to the Standard Laptop service catalog item.

## Milestone 3 – Service Catalog

A Standard Laptop request was placed through the Service Catalog. The request was approved and the resulting Requested Item and Catalog Task were verified.

## Final Output

The automation successfully creates a Catalog Task with the required short description and assigns it to the Hardware group.

## Tools Used

- ServiceNow
- Flow Designer
- Service Catalog
