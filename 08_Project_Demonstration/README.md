# Phase 8 – Project Demonstration

## Demonstration

The completed IT Procurement – Laptop Automation project was demonstrated using ServiceNow.

## Demonstration Steps

1. Open the Service Catalog.
2. Select Standard Laptop.
3. Place the laptop request.
4. Open the Request record.
5. Verify the approval.
6. Open the Requested Item.
7. Open the Catalog Task.
8. Verify the Short Description.
9. Verify the Assignment Group as Hardware.
10. Verify the final task status.

Screenshots of the ServiceNow workflow, Request, Requested Item, Standard Laptop tasks and final Catalog Task are available in this repository.
