# Phase 2 – Requirement Analysis

## Functional Requirements

1. The user should be able to place a Standard Laptop service request.
2. The request should go through the required approval process.
3. After approval, the Flow should create a Catalog Task automatically.
4. The Catalog Task should have the required short description.
5. The Catalog Task should be assigned to the Hardware assignment group.

## Tools Required

- ServiceNow
- Flow Designer
- Service Catalog

## Expected Result

After the Standard Laptop request is approved, a Catalog Task should be created automatically and assigned to the Hardware group.
