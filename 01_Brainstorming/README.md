# Phase 1 – Brainstorming & Ideation

## Project Title
IT Procurement – Laptop Automation

## Problem Statement
The laptop procurement process can involve multiple manual steps such as placing a service request, obtaining approval, and creating a catalog task.

## Proposed Solution
Automate the standard laptop procurement process using ServiceNow Flow Designer.

## Idea
When a Standard Laptop service request is processed and approved, the Flow automatically creates a Catalog Task and assigns it to the Hardware assignment group.

## Expected Outcome
The automation reduces manual work and ensures that the laptop procurement request is processed consistently.
