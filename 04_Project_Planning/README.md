# Phase 4 – Project Planning

## Project Plan

The project is planned in three main milestones.

### Milestone 1 – Flow
- Create the Standard Laptop Task flow.
- Configure the Service Catalog trigger.
- Add the Create Catalog Task action.
- Set the required task details.
- Set Assignment Group as Hardware.
- Save and activate the flow.

### Milestone 2 – Flow Assignment
- Open the Standard Laptop catalog item.
- Configure the Process Engine.
- Remove unnecessary automations.
- Assign the Standard Laptop Task flow.

### Milestone 3 – Service Catalog
- Open the Service Catalog.
- Select Standard Laptop.
- Place the order.
- Complete the approval process.
- Open the Request and Requested Item.
- Verify the Catalog Task.
- Confirm the short description and Hardware assignment group.

## Project Goal

To automate the standard laptop procurement process and reduce manual task creation.
